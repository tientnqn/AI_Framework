This is the project that define the colaboration enviroment for R&D Department on Developing, Deploying and maintaining agents that serve for R&D team members.
This project include:
- 00_mindset: Introduce the mindset of authors on creating and operating agents
- 01_prompting_guide: Rules when prompt
- 02_agent_architecture: Design architect on that agents are created and operated
- 03_use_cases: Describe main use cases that R&D team have to accomplish
- 04_evaluation: Describe rules that agents must be follow and how they evaluate that their tasks are success.
